# 长篇小说阶段一：长线卖点与金手指体系策划规范

> **定位**：长篇网络连载小说的核心地基与商业卖点设计。
> **适用体量**：30万 ~ 200万字+

---

## 一、 长篇长线金手指设计原则

金手指是长篇主角立足的根本，设计必须经得起百万字推敲，严禁“前期逆天、后期无用”或“设定矛盾崩盘”：

### 1. 明确金手指的“输入-处理-产出”模型
* **输入成本**：金手指运作需要消耗什么？（声望值、寿元、击杀敌人掉落、情绪值、气运、真金白银、或是按时签到？）
* **处理机制**：金手指如何转化？（加点推演、无上顿悟、万倍返还、词条合成、因果倒装、人生重拟？）
* **产出反馈**：得到的是什么？（技能突破、神级功法、神兽幼崽、未来信息差、宗门气运？）
* **不可逾越的红线与代价**：金手指绝对不能无敌无脑全知全能，必须有冷却时间、境界壁垒或某种负面牵制，才能维持持久的危机感与戏剧张力。

### 2. 金手指的阶段性升级路线图
长篇的金手指必须能随着主角换地图而成长：
- **阶段一（新手期）**：基础功能启动，解决近在眼前的生死危机与资源匮乏；
- **阶段二（中层期）**：解锁第二核心功能（如从单体加点扩展到群体推演或空间拓展），支撑跨境界击杀；
- **阶段三（高层期）**：触及世界底层法则，金手指本身的身世/来源成为全书终极主线的一部分（如金手指是天道残片或远古创世信物）。

---

## 二、 主角核心动机（长线驱动力）

短篇主角往往是“被欺负后反击”；长篇主角**绝不能被动挨打**，必须具备主动出击的长线驱动力：
1. **生存迫切感**：寿命倒计时、灭族诅咒、三年必死之局；
2. **野心与执念**：重整家族、登临无上绝巅、打破吃人世道、立人族万世太平；
3. **羁绊与守护**：寻回走失至亲、治愈濒死白月光、复活守护残魂。

## 三、 标准交付物卡片模板

输出给作者确认时，必须包含以下标准化模块：

```markdown
### 📘 《书名暂定》长线卖点与金手指体系方案

1. **核心赛道与标签**：[如：东方玄幻·苟道推演·词条升级流]
2. **一句话长线核心梗**：[如：别人苦修百年渡劫飞升，我靠给万物提取词条，把凡铁合成成了开天神剑。]
3. **主角档案与处境**：[姓名、当前卑微身份、直接生存危机]
4. **金手指完整机制**：
   - 名称：[如：万物万灵词条鼎]
   - 运作原理：[输入、转化、产出]
   - 约束与限制：[每天限用一次 / 需要消耗特定气血]
   - 升级阶段规划：[1-100章功能 / 100-300章解锁 / 300章后终极功能]
5. **核心爽感闭环**：[读者为何会一直追读？满足何种心理？]
6. **全书终极目标**：[主角最后要达到何种高度？解决何种宇宙终极矛盾？]
```

**🛑 强制确认节点**：输出后停步，等待作者确认或修改金手指与动机设定。
